# .qgw/ 目录说明

本目录是 QGW 的项目本地覆盖目录。在此目录中的文件会覆盖 skill 默认配置。

## 目录结构

```
.qgw/
├── config.json              # 项目 QGW 配置
├── constitution.md          # 项目 constitution（替代 CLAUDE.md 声明）
├── anti-patterns.md         # 项目专属 anti-patterns（追加到全局规则之后）
├── templates/
│   ├── advisor-pm.md        # 覆盖 PM 顾问 prompt 模板
│   ├── advisor-arch.md      # 覆盖架构师顾问 prompt 模板
│   ├── verifier-gate1.md    # 覆盖 Gate 1 verifier prompt 模板
│   ├── verifier-gate2.md    # 覆盖 Gate 2 verifier prompt 模板
│   └── report-template.md   # 覆盖报告输出模板
└── overrides/
    └── gate1-steps.md       # 覆盖或追加 Gate 1 工作流步骤
```

## 优先级

```
1. .qgw/ 项目本地覆盖（最高优先级）
2. skill 默认 references/
```

## 快速开始

1. 在项目根目录创建 `.qgw/` 目录
2. 按需创建覆盖文件（只需创建需要覆盖的部分）
3. 未创建的文件自动使用 skill 默认配置

## 注意事项

- 禁止直接修改 `~/.agents/skills/quality-gate-workflow/` 下的文件（反模式 #43）
- `.qgw/anti-patterns.md` 必须遵循全局格式（反模式 #44）
- 覆盖文件修改后立即生效，无需重新安装 skill
