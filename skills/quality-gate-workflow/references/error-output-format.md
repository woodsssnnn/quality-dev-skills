# 错误输出格式

> 本文档由 SKILL.md 路由按需加载（检测到反模式时）。

当检测到反模式时，使用人类可读的错误输出：

```
❌ 操作被阻止：[人类可读的描述]
   原因：[为什么这违反了工作流]
   建议：[用户应该怎么做]
   参考：反模式 #N（详细信息见 anti-patterns.md）
```

## 示例

```
❌ 操作被阻止：验收标准描述模糊，无法验证
   原因："有筛选功能"不够具体，验收标准要求可验证（反模式 #5）
   建议：改为"筛选器=流程树多选，支持按节点类型过滤 (§6.1.1)"
   参考：反模式 #5（详细信息见 anti-patterns.md）
```

```
❌ 操作被阻止：verifier 未通过 Task/Agent 工具派发
   原因：S4 必须通过独立 verifier 子代理验证（反模式 #1）
   建议：使用 Task/Agent 工具调用 verifier，将 toolCallId 写入验收 JSON
   参考：反模式 #1（详细信息见 anti-patterns.md）
```

```
❌ 操作被阻止：PRD 变更后未声明影响级别
   原因：PRD 变更必须调用 prd-changed 声明影响级别（反模式 #59）
   建议：运行 python gate-enforcer.py prd-changed --impact cosmetic|minor|major
   参考：反模式 #59（详细信息见 anti-patterns.md）
```

## 错误级别

| 级别 | 行为 | 示例 |
|------|------|------|
| **BLOCK** | 阻断操作，必须修复后重试 | 前置条件不满足、产出物缺失、红线违规 |
| **WARN** | 警告但不阻断 | 非关键检查失败、建议性改进 |
| **INFO** | 信息提示 | 步骤完成、进度更新 |
