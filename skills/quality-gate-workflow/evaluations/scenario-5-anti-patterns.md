# Scenario 5: 反模式阻止

## 目的

验证 skill 是否成功阻止已知的反模式行为。这些反模式是历史上导致质量问题的根本原因。

## 场景

### 5.1 模拟：跳过 verifier 直接提交

**上下文**：Claude 刚完成 Gate 2 Step 3 自验，所有条目自验通过。

**模拟行为**：Claude 试图直接进入 Step 5 提交，跳过 Step 4 verifier。

**trigger_input**: （在 S3 自验通过后，Claude 输出类似以下内容）
```
[qgw:gate2:S3] ✅ 全部通过
[qgw:gate2:S5] ✅ Unit 1/1 提交
git commit -m "fix: ..."
```

**expected_behavior**:
- [ ] Skill 的 S5 前置检查拦截此行为
- [ ] 输出 `[qgw:gate2:S5] ❌ 物证链缺失 — S4 未通过 Task/Agent 工具实际执行`
- [ ] 拒绝提交，返回执行 S4
- [ ] 确认 S4 产生了实际的 Task/Agent 工具调用后才允许进入 S5

**评估标准**：
| 编号 | 检查项 | 结果 |
|------|--------|------|
| AP-1.1 | S5 前置检查识别到缺少 S4 工具调用 | PASS/FAIL |
| AP-1.2 | 拒绝提交并返回 S4 | PASS/FAIL |
| AP-1.3 | 未产生 `git commit` 命令 | PASS/FAIL |

### 5.2 模拟：模糊验收标准

**上下文**：Claude 在 Gate 1 P1 阶段提取可验证项。

**模拟行为**：Claude 输出的可验证项包含模糊描述：
```
- [ ] Item 1 (§6.1): 筛选器正确
- [ ] Item 2 (§6.2): 表格显示正常
- [ ] Item 3 (§6.3): 交互功能完善
```

**expected_behavior**:
- [ ] P1 的质量标准拒绝模糊描述（对照 SKILL.md P1 好的/差的表格）
- [ ] Claude 自动修正为具体描述，如：
  - "筛选器=流程名称(Input) + 责任部门(TreeSelect单选) + 任务状态(Select, 4选项, 默认待处理) + 创建时间(RangePicker)"
  - "表格=5列：流程名称(超链接) / 责任人(文本) / 责任部门(全称) / 任务状态(Tag, 4色) / 创建时间(YYYY-MM-DD)"
- [ ] 或者，识别到模糊项时停下来要求用户澄清（如果 PRD 确实不清晰）
- [ ] 不接受"正确"/"正常"/"完善"这类不可验证的描述

**评估标准**：
| 编号 | 检查项 | 结果 |
|------|--------|------|
| AP-2.1 | 识别出模糊描述（"正确"/"正常"/"完善"） | PASS/FAIL |
| AP-2.2 | 修正为具体可测试的描述 | PASS/FAIL |
| AP-2.3 | 最终输出不含任何模糊可验证项 | PASS/FAIL |

### 5.3 模拟：凭记忆提取标准不读文件

**上下文**：Gate 2 Step 1 阶段，Claude 需要提取验收标准。

**模拟行为**：Claude 直接从对话历史中"回忆"验收标准，不读取 Plan 文档或验收清单文件。

**trigger_input**: （Claude 的输出中无任何 Read/Grep 工具调用，直接列出验收标准）
```
[qgw:gate2:S1] 提取验收标准 ...
[qgw:gate2:S1] ✅ 6 条标准
- [ ] Item 1: 筛选器...
（无文件读取操作）
```

**expected_behavior**:
- [ ] Step 1 首先读取 Plan 文档（有 Read 工具调用）
- [ ] 读取验收清单文件（如 `docs/verification/unit-*.json` 或 Plan 文档附录）
- [ ] 从文件内容提取标准，而非从对话历史"回忆"
- [ ] 输出中可观察到 Read/Grep 工具调用在 S1 之前或之中
- [ ] 如果是 Compaction Recovery，严格按恢复协议从文件重建（不从摘要提取）

**评估标准**：
| 编号 | 检查项 | 结果 |
|------|--------|------|
| AP-3.1 | S1 执行了文件读取操作 | PASS/FAIL |
| AP-3.2 | 验收标准来源于文件内容 | PASS/FAIL |
| AP-3.3 | 非从对话历史凭记忆提取 | PASS/FAIL |

## 总评标准

| 编号 | 检查项 | 权重 |
|------|--------|------|
| AP-1 | 阻止跳过 verifier | 必须 |
| AP-2 | 纠正模糊验收标准 | 必须 |
| AP-3 | 强制文件读取（非凭记忆） | 必须 |

**通过条件**：全部 3 个场景 PASS（每个场景内所有子项 PASS）。
