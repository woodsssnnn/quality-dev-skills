# Scenario 2: Gate 1 流程遵循

## 目的

验证 Gate 1 是否严格按 P1→P5 流程执行，每个步骤的产出物是否符合规范。

## 前置条件

- 已加载 quality-gate-workflow skill
- 已加载项目的 dev_rule_path 或 gate_dev_rules 配置

## 模拟 PRD

以下是一段模拟 PRD，用于触发 Gate 1 PRD 模式：

```
## 需求：任务列表筛选器

### 6.1 筛选区域
页面顶部包含以下筛选条件，水平排列：
1. 流程名称 — 文本输入框，支持模糊匹配
2. 责任部门 — 树选择器，单选
3. 任务状态 — 下拉框，选项：待处理/进行中/已完成/已关闭，默认"待处理"
4. 创建时间 — 日期范围选择器

### 6.2 表格列
| 列名 | 类型 | 说明 |
|------|------|------|
| 流程名称 | 文本 | 超链接，点击跳转流程详情 |
| 责任人 | 文本 | 显示姓名 |
| 责任部门 | 文本 | 显示部门全称 |
| 任务状态 | Tag | 待处理=蓝色/进行中=橙色/已完成=绿色/已关闭=灰色 |
| 创建时间 | 日期 | YYYY-MM-DD 格式 |

### 6.3 交互
- 点击"查询"按钮触发筛选
- 点击"重置"按钮清空所有筛选条件，恢复默认（任务状态="待处理"）
- 表格支持分页，每页 20 条
```

**trigger_input**: "根据PRD写计划，PRD路径: [上述模拟PRD]"

## 预期行为

### P1: 解析需求 → 提取可验证项

- [ ] 输出 `[qgw:gate1:P1] 解析需求 → 提取可验证项 ...`
- [ ] 提取的可验证项覆盖全部 5 个要素：4 个筛选器 + 1 个默认值
- [ ] 提取的可验证项覆盖全部 5 个表格列，含 Tag 颜色映射
- [ ] 提取的可验证项覆盖 3 个交互行为
- [ ] 每个可验证项附带 §X.X 引用（如 §6.1、§6.2、§6.3）
- [ ] 可验证项具体可测试（如"任务状态 Tag: 待处理=蓝色"而非"颜色正确"）
- [ ] 输出 `[qgw:gate1:P1] ✅ N 项可验证项, M 个 unit`

### P2: 撰写计划

- [ ] 输出 `[qgw:gate1:P2] 撰写计划 ...`
- [ ] 每个 plan unit 明确引用 P1 可验证项（含 §X.X 引用）
- [ ] 每个 plan unit 指定 What（映射可验证项）、Where（文件路径）、How（方法）
- [ ] 如有 dev_rule_path 或 gate_dev_rules，每个 plan unit 指定架构模式
- [ ] 输出 `[qgw:gate1:P2] ✅ N 个 plan unit`

### P3: 自验计划完整性

- [ ] 输出 `[qgw:gate1:P3] 自验计划完整性 ...`
- [ ] 逐条检查每个可验证项：Covered / Missing / Ambiguous
- [ ] 如有缺口则修复后重新检查
- [ ] 输出 `[qgw:gate1:P3] ✅ 全部覆盖`

### P4: 独立 verifier 子代理

- [ ] 输出 `[qgw:gate1:P4] 派独立 verifier 子代理 (round 1)`
- [ ] 实际调用 `Task` 或 `Agent` 工具（非仅输出日志文本）
- [ ] 子代理 prompt 包含：可验证项、需求位置、Plan 位置、逐项报告指令
- [ ] 子代理返回 COVERED / MISSING / PARTIAL + 证据
- [ ] toolCallId 被写入验收清单
- [ ] 输出 `[qgw:gate1:P4] ✅ 全部 COVERED` 或修复后重验

### P5: 通过 → 移交 Gate 2

- [ ] 输出 `[qgw:gate1:P5] → 验收清单持久化 → 移交 Gate 2`
- [ ] 验收清单追加到 Plan 文档末尾（Markdown 格式）
- [ ] 验收清单同时写入结构化 JSON
- [ ] 移交内容包含 Plan 文档、JSON、澄清文件（如有）

## 评估标准

| 编号 | 检查项 | 权重 |
|------|--------|------|
| G1-1 | P1 可验证项完整且具体 | 必须 |
| G1-2 | P1 每个 item 有 §X.X 引用 | 必须 |
| G1-3 | P2 每个 unit 映射可验证项 | 必须 |
| G1-4 | P3 逐条自验（非笼统说"没问题"） | 必须 |
| G1-5 | P4 实际调用 Task/Agent 工具 | 必须 |
| G1-6 | P4 toolCallId 非空 | 必须 |
| G1-7 | P5 验收清单持久化到文件 | 必须 |

**通过条件**：全部 7 个检查项 PASS。
