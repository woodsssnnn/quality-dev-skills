# Scenario 2: 已有 .qgw/ 时的覆盖/合并/取消

## 触发条件

用户执行 `--init` 且项目目录中已存在 `.qgw/` 目录和 `config.json`。

## 输入

```
--init
```

项目状态：已有 `.qgw/config.json`（旧版本配置），`docs/` 目录已存在。

## 期望行为

1. 检测到已有 `.qgw/` 目录
2. 提示用户已有配置的存在，提供三个选项：
   - **覆盖**：删除旧配置重新生成
   - **合并**：保留用户自定义字段，更新版本号和新增字段
   - **取消**：不执行任何操作
3. 选择覆盖时：备份旧 `config.json` 为 `config.json.bak` 后重新生成
4. 选择合并时：仅更新 `version` 字段，保留 `presets`、`custom_rules` 等用户字段
5. 选择取消时：输出 "初始化已取消" 并退出

## 验证标准

- [ ] 检测到已有 `.qgw/` 目录并明确提示
- [ ] 三选项（覆盖/合并/取消）均被提供
- [ ] 覆盖模式下 `config.json.bak` 被创建
- [ ] 合并模式下用户自定义字段被保留
- [ ] 取消模式下无任何文件变更
